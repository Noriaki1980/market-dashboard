# Market Dashboard

日経平均・NYダウ・S&P500・ドル円・ユーロ円・ポンド円・豪ドル円・豪ドル/米ドルの直近値とチャート、
および個別ポートフォリオ（銘柄・保有株数・基準日）のパフォーマンス、リスク・リターンと効率的フロンティアを表示する GitHub Pages 用ダッシュボード。

```
index.html                     ダッシュボード本体（単一HTML / Chart.js）
config/portfolio.json          ポートフォリオ設定（銘柄・基準日）
scripts/fetch_data.py          yfinance で日足終値を取得 → data/market.json
.github/workflows/update-data.yml  定期取得（約3時間おき）＋設定変更時に取得
data/market.json               自動生成（Actions がコミット）
```

## セットアップ（GitHub Desktop）

1. このフォルダを新しいリポジトリとして作成し、`main` に push
2. GitHub のリポジトリ → **Settings → Pages** → Source: `Deploy from a branch` / `main` / `/ (root)`
3. **Settings → Actions → General → Workflow permissions** を `Read and write permissions` に
4. **Actions** タブ → `Update market data` → **Run workflow**（初回データ作成）
5. `https://<user>.github.io/<repo>/` を開く

以後は平日・土曜朝に約3時間おきに自動更新（GitHub 側の都合で数十分遅れることがあります）。
価格に変化がないときはコミットしません。

## 銘柄の追加・削除

- **画面から**: 下部フォームで追加・削除・保有株数と基準日の変更 → このブラウザに保存（PC とスマホは別々）
- **全端末に反映**: 「設定JSONをコピー」→ `config/portfolio.json` に貼り付けて push
  （github.io で開いている場合は「GitHubで編集」ボタンで直接編集画面へ）。
  push すると Actions が走り、新しい銘柄の価格が取得されます。

銘柄コードは Yahoo Finance 形式: 日本株 `7203.T`（画面では `7203` と入力すれば自動で `.T`）、米国株 `AAPL`、ETF `1306.T` / `VOO` など。

## 計算方法

- **前日比**: 直近終値 ÷ 前営業日終値 − 1
- **前週末比**: 直近終値 ÷ 前週の最終営業日終値 − 1
- **ポートフォリオ指数**: 最初の基準日 = 100。配当は含まない（終値ベース）。時間加重で連結
  - 株数加重（既定）: 各銘柄を基準日から保有株数だけ持っていたものとして計算。株数0の銘柄は含めない
  - 等金額: 各銘柄をそれぞれの基準日の終値で同じ金額だけ組み入れたものとして計算
  - 円換算OFFのとき、外貨銘柄は最新の為替レートで固定換算して合算（為替変動を含めない）
- **評価額・構成比**: 保有株数 × 直近値 × 最新の為替レート（円）
- **リスク・リターン**: 推計期間（6M / 1Y / 2Y / 基準日〜）の週次または日次の単純リターンから
  平均×52（252）を期待リターン、標準偏差×√52（√252）をリスクとする
- **効率的フロンティア**: 空売りなし（ウェイト0〜100%、合計100%）の平均分散最適化。
  最小分散、最大シャープ（無リスク金利を指定可）、資本市場線、参考のランダムな組合せ1,500個を表示。
  最大シャープの株数目安は現在の評価額合計を最大シャープのウェイトで配分した株数（日本株は100株単位で丸め）
- **円換算**: 各日の終値 × その日以前で直近の為替終値（USD→`JPY=X`, EUR→`EURJPY=X`, GBP→`GBPJPY=X`, AUD→`AUDJPY=X`）
- 日米の休場日は直前値で補完

## メモ

- yfinance は非公式 API のため、一時的に取得できないことがあります。失敗した銘柄は前回値を残し、画面上部に表示します
- 市場が開いている時間帯の取得では、最終行はその時点の値（暫定）です
